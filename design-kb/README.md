# design-kb

A UI/UX and design-engineering knowledge base: 25 markdown docs exported from a claude.ai Project. This folder is reference material, not a skill (it has no SKILL.md).

Start at [`kb/README.md`](kb/README.md). It holds the index, known conflicts between docs, licensing flags and gaps.

| Path | What is in it |
|---|---|
| `kb/ux-mastery.md` | UI/UX principles and foundations |
| `kb/ui-craft.md`, `kb/motion.md`, `kb/ux-research.md`, `kb/pm-brand.md`, `kb/validation.md`, `kb/open-design.md` | Craft, motion, research, PM/brand, validation notes and the open-design review |
| `kb/ui-core.md`, `kb/ui-components.md` | shadcn/ui, Base UI, Radix and the component libraries |
| `kb/resources/` | Per-library verification and resources (see `kb/resources/README.md`) |
| `claude/` | Source indexes: UI libraries, design skill repos, sources with licenses |

Notes:
- Local clone paths mentioned inside the docs (for example `/home/claude/...`) were session-local and do not exist in this repo.
- The docs record the upstream licenses of the sources they describe. Check `claude/design-sources-index.md` before copying text from any listed repo. Some sources are CC BY 4.0, Apache 2.0 or have no license file.
- Facts about versions, dates and prices were checked on 2026-11-12 and go stale. Re-verify before relying on them.

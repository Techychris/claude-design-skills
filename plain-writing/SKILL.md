# Plain writing

Apply these rules while drafting, then run the check pass before delivering. Use this instead of the remove-ai-tells skill when the goal is writing cleanly from the start, not only cleaning up an existing draft.

## Rules

1. Lead with the answer. No openers, praise, or restating the question.
2. State claims directly. Don't frame them as "not X, but Y" unless someone actually claimed X.
3. List as many items as actually exist. Never pad to three.
4. Prefer specifics (numbers, names, examples) over abstractions. If you can't be specific, write less.
5. Never invent a specific to satisfy rule 4. A specific you haven't verified gets labeled as an estimate, or gets cut.
6. One descriptor per noun. Use metaphors only when they explain something a plain statement can't.
7. Avoid: delve, tapestry, landscape, robust, nuanced, crucial, pivotal, underscore, intricate, testament, journey, "it's worth noting." Don't swap in synonyms that do the same job (explore, multifaceted, realm); rewrite the sentence instead.
8. No suspense reveals ("The result? X.") or rhetorical questions you answer yourself.
9. Hedge only by naming what the answer depends on. Never hedge generically ("results may vary").
10. When evidence favors one side, say so. Don't manufacture balance.
11. No closing summary or offer of further help.
12. Use headers and bullets only when the content is a list or reference. Otherwise write prose.
13. Use periods and commas instead of em dashes.

## Check pass (run on the finished draft)

1. **Topic-swap test:** for each sentence, ask whether it would still make sense about an unrelated topic. If yes, cut it or make it specific.
2. **Third-item test:** for every list of three, check whether the third item is distinct from the first two. If it overlaps or is vague, drop it.
3. **Contrast test:** for every "not X but Y" or "isn't just", check whether anyone claimed X. If not, state Y alone.
4. **Specifics audit:** confirm every number, name, and date is verified or labeled as an estimate.
5. **Surface scan:** search the draft for em dashes, the rule 7 words, "In summary", "Let me know", and question marks followed by an answer.
6. **Length check:** if the draft is longer than the content requires, cut sentences that add no new information.

Report nothing about the check pass unless asked; deliver the cleaned text.

## Why these rules exist (context, not instructions)

These patterns make text look thorough to a quick reader without adding content. Preference training has been shown to reward surface qualities like length and agreeableness over substance, and these tells are likely the same effect. Generic phrasing is also safe because it can't be wrong, so it crowds out checkable claims. The topic-swap test and specifics audit target that root cause; the word list only catches symptoms.
